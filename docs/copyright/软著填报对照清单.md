## 一、为什么这个页面必须你本人填

1. **本会话没有浏览器/屏幕控制能力**，无法点击、输入或接管你已打开的页面。
2. **即便能操作也不该代填**。办理流程是「账号注册 → **本人实名认证** → 在线填报 → 上传材料 → 打印申请确认签章页 → **本人亲笔手抄承诺 + 签名 + 身份证号** → 扫描上传」。实名核验与签章页在法律上都属于本人行为。
3. **2026-03-15 新规是硬红线**：新版申请表签章页要求经办人用黑色中性笔亲笔抄写承诺，明确包含「**未使用 AI 开发编写代码、撰写文档或生成登记申请材料**」，并签名、填写身份证号码；严禁打印、代签、涂改，违规材料无效。由 AI 把内容填进表单，实质就是 AI 生成登记申请材料，属于被从严审核的「非正常申请」，可能被列入版权登记失信名单并纳入个人征信。
4. 「主要功能和技术特点」由 **200 字以内提高到 500–1300 字**，须完整说明研发背景、核心架构、功能模块、技术实现、应用场景，杜绝模板化。这段必须本人基于真实研发过程撰写。

## 四、功能描述写作提纲（本人按此用自己的语言写，不是成稿）

按五个维度各写一段**具体事实**，避免「本系统功能完善、界面友好」这类模板句：

1. **研发背景与目的**：面向小学三至六年级英语字母/词汇听辨练习，要解决的具体问题，为什么选择自研而非套用现有引擎。
2. **核心架构**：原生 Canvas 2D 单画布 + 状态机（nav / home / playing / gameover / confirmExit 等）；`game.js` 主逻辑、`config` 配置、`data` 词库、`utils` 音频、`platform` 微信平台 API 收口层（含转发分享能力）、`scripts/build.js` 构建；CommonJS 组织；无 npm 依赖、无网络请求、无第三方 SDK。
3. **功能模块**：找字母、拼单词、对对碰、拼写练习；年级/册次数据驱动选择；单词发音与回退；计分与生命、结算与再来一局；按册分包加载；微信小游戏平台适配。
4. **技术实现**：`requestAnimationFrame` 主循环、触摸命中判定、数组洗牌、圆角矩形绘制、首次触摸解锁音频、分包加载策略、构建期生成发音清单与产物。
5. **应用场景**：微信小游戏，课堂辅助或家庭课外练习，弱网/离线可玩。

**一致性检查**：软件名称、功能描述、源代码三者必须完全对应；描述里出现的功能必须能在代码里找到，代码里没有的功能不要写。

## 五、新规红线与常见补正点

- 旧版申请表自 2026-03-15 起废止，用旧表直接不予受理。
- 功能描述少于 500 字、模板化、AI 批量炮制 → 补正或驳回；当前补正率与驳回率明显上升。
- 手抄承诺必须亲笔黑色中性笔；打印、代签、涂改 → 材料无效。
- 名称含版本号/广告语、页眉版本号与申请表不一致、源程序每页少于 50 行、文档每页少于 30 行 → 补正。
- 提交虚假材料、短期集中申报、内容与软件实际脱节 → 列入失信名单、纳入征信。
- 补正须在通知后 **30 日内**提交，逾期视为撤回。审查自受理日起 60 日内完成；实务约 30–60 工作日，新规后可能更长。
- 自行提交**无官费**（2017 年起取消）；变更/补充登记 150 元、合同登记 100 元；加急另付费。
- 登记完成后在用户中心下载 PDF 电子证书，终身有效、无需续展。
