## 四、玩法事实（写「主要功能」时用，全部有代码依据）

### 找字母模式（`FIND_LETTER_ENABLED = true`，已开放）
- 玩法：**App 播报字母 → 玩家在掉落字母中点中对应项**（听音辨形，反向认读）。
- 每组 6 个字母，3 列 × 2 排；正确答案大小写合计最多出现 2 次。
- 3 条生命；目标字母落地漏掉扣 1 命；点中 +1 分，点错干扰项 −1 分。
- 每完成 10 组升一档速度，`speedForLevel()` 按基础速度 0.09 逻辑像素/毫秒、每档 +15% 递增。
- 字母发音播两遍（`announceLetter`），首次触摸解锁音频（`unlockAudio`）。
- 退出需二次确认；结算页可再来一局。

### 拼单词模式（6 种子模式）
1. **听音拼单词**（`listen`）：播放单词发音，从打乱的候选字母方块中按顺序拼出单词；过滤含空格短语；进入时自动播一遍。
2. **中文转单词**（`cn`）：看中文释义拼出单词，不自动发音。
3. **全部单词**（`words`）：浏览本单元所有单词，数据驱动滚动列表。
4. **单词对对碰**（`match`）：点英文卡听发音，英中配对消除；按屏幕尺寸自动计算铺满的网格，随机取词，含颜色插值动画（`lerpColor`）、完成态。
5. **字母连连**（`link`）：从当前章节抽纯字母单词（长度 2~8），**每局词数按单词长度动态决定**——以目标词字母累计占格达到网格容量的 62% 为收手条件，并限制在 4~8 个之间，短词章节多放、长词章节少放；按横 / 竖 / 一次转弯的 L 形路径摆进 6 列 × 8 行网格，其余格子填干扰字母。按住拖动经上下左右相邻格连成单词，松手结算，正向反向都算连对，往回划撤销上一格；连对播真实单词发音并弹出复用弹框。右上角提供「大写版 A~Z / 小写英文版 a~z」切换，网格字母（含干扰字母）与连对弹框里的单词同步改变大小写，内部网格数据恒存大写、判定统一转小写比较，切换不重置本局进度，默认版本由 `LINK_DEFAULT_LOWERCASE` 控制。目标词提示始终显示中文，连对后也只是加勾，不替换成英文；提示为 2 列布局，按「未找到在前、已找到沉底」动态排序，行高字号随词数自适应，仅该列表区在放不下时可上下滑动。路径生成与合法性校验在 `utils/link.js`（纯函数，支持任意行×列矩形网格），`tools/check_link.js` 做 600 局三档词长分布自检。
6. **单词听写**（`dictation`）：按当前章节词表（去重、含短语）顺序听写，屏幕始终显示中文释义作题目、英文默认遮住（点卡片揭晓）。**四种发音模式**只决定发音内容与顺序：`cn` 先读中文释义再读英文、`en` 只念英文、`both` 先念英文再读释义（先听后对答案）、`cnOnly` 只念中文释义（屏幕已给出中文，仅作听音巩固、不读英文）；两个片段间隔 `DICT_GAP_MS=650`，由 `utils/audio.js` 的 `speakSequence()` 串行播放，片段用独立 `InnerAudioContext` 播完即销毁，并以代号 `seqGen` 打断旧序列、避免叠音。**时间间隔**可选 5/10/15/30 秒（`DICT_INTERVALS`），到点自动切下一个词并循环；页面提供「上一个 / 暂停·继续 / 下一个」按钮，手动切换后重新计时，暂停时停发音、进度条清空。英文清单缺失或分包未就绪时回退逐字母拼读；中文清单缺条时自动跳过中文、只播英文。发音顺序与循环下标的纯逻辑在 `utils/dictation.js`（无平台 API），`tools/check_dictation.js` 自检三种顺序、循环边界、间隔档位与中英文两套清单一一对齐（944/944）；中文释义发音由 `tools/gen_cn_audio.py` 用 edge-tts 生成。
- 路径：导航页 → 年级/册次（6 册）→ 章节（含全部章节）→ 模式选择 → 练习。
- 拼写页候选字母每行 5 个，复用找字母的彩色方块视觉；`toggleCandidate()` 处理选中/回退。

### 词库与数据
- `data/book_index.js`：年级/册次/章节索引，含 `slug()` 词条转文件名规则（小写、空格转下划线、去撇号、保留连字符）。
- `data/words.js`、`words_b34.js`、`words_g456.js`：教材词表；`words_b56_legacy.js` 为留存资料，未接入游戏、已从构建产物排除。
- `data/word_audio.js` 963 行：按册次记录已生成发音的文件名清单，由构建期脚本自动重建。
- 发音由 `tools/gen_words_audio.py`（edge-tts）在**构建期**生成 mp3，运行时只播放包内资源，不联网。

### 音频与分包技术
- `utils/audio.js`：`speakLetter` / `announceLetter` / `announceWord` / `speakWord` / `unlockAudio`；每遍使用独立临时 `InnerAudioContext` 避免 `stop/play` 截断。
- 真实单词发音上下文按「年级 + 词条」缓存复用；`onCanplay` 兜底补播。
- `loadGradeAudio()` 按年级加载分包音频，带进度、成功、失败回调，失败进入 `loadFail` 状态可重试。
- 包内音频路径带回退：`adapter.audioSrcCandidates()` 返回候选列表，播放报错时依次切换重试；优先 `/assets/...` 绝对路径，失败后改用不带前导斜杠的相对路径，全部失败才回退逐字母拼读。这一回退主要应对部分环境（如 PC 模拟器 Web 容器）把前导斜杠当成站点根 URL 导致 404 的情况。

### 通用绘制与交互
- `requestAnimationFrame` 驱动的主循环 `loop()`，按 `dt` 更新（`update(dt)`）。
- `roundRectPath()` 自绘圆角矩形、`shuffled()` 洗牌、`hit(rect, px, py)` 矩形触摸命中、`getPoint(e)` 统一触摸坐标。
- `drawMenuCard()` / `drawButton()` / `drawBackButton()` / `drawSpeaker()` 等复用组件；颜色插值 `hexToRgb` + `lerpColor`。
- 本地存储用 `getStorageSync` / `setStorageSync`（最高分等）。
- 字体：Andika（小写 a/g 为课本标准双体结构，贴近小学英语印刷体），`loadFont` 加载，失败回退 `sans-serif`。
