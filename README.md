# 字母掉落 · 微信小程序版（letterdrop-wx）

**反向玩法（听音点字母）**：App 用标准语音**播报一个字母**，屏幕上**6 个字母分两排从顶部掉落**（每排 3 个），玩家要在落地前**点中**与播报对应的字母。适合幼儿英语启蒙——孩子不用打字/说话，听音辨形即可。基于原生微信小程序（WXML / WXSS / JS）开发。

> 与原"念字母识别"方案不同，本版**完全离线**：语音播报用包内预录的标准发音文件，无需任何插件、云端或网络。

## 玩法规则
- 每组掉落 **6 个字母（3 列 × 2 排）**；
- 开局 App **播报目标字母**，并在顶部**醒目显示**「请找出 X」；
- 每组中**正确答案最多出现 2 个**（大小写合计，即目标字母可能以大写/小写出现 1~2 次），其余为干扰项；
- **点中正确字母 +1 分**；**点错（点到干扰项）扣分**（不低于 0）；
- 目标字母**落地（漏点）则扣 1 生命**，3 次后游戏结束，弹出结算卡片（含最高分）；
- **慢慢变快**：每完成 **10 组**速度 +1 档，无上限；
- 字母大小写随机显示，**不区分大小写**（B 与 b 都算对）；
- 最高分本地存储（`wx.setStorageSync`），重玩自动刷新。

## 技术栈与结构
```
letterdrop-wx/
├── app.js / app.json / app.wxss   全局入口、页面注册、主题样式
├── project.config.json           工程配置（appid: wxe988a5f8708ecad3）
├── sitemap.json
├── assets/audio/                  ★ 26 个字母标准发音 mp3（A.mp3 … Z.mp3）
├── config/
│   └── gameConfig.js             ★ 玩法参数（组大小/列数/提速/计分等）+ 外研版词库
├── utils/
│   └── audio.js                  ★ 离线播放字母发音（包内 mp3，无插件/云）
└── pages/
    ├── index/                    主页：背景 + 开始按钮 + 最高分
    └── game/                     游戏页：Canvas 掉落 + HUD + 结束卡片
```
- 渲染：`canvas type="2d"` + `requestAnimationFrame` 游戏循环；
- 音频：`wx.createInnerAudioContext()` 播放 `/assets/audio/<字母>.mp3`，`obeyMuteSwitch=false`（静音模式也播报）；
- 存储：`wx.setStorageSync('letterdrop_best')`；
- **无任何云端/插件依赖**，导入即可编译运行。

## 运行 / 调试
1. 打开 **微信开发者工具** → 导入项目 → 选择本目录；
2. AppID 已配置为 `wxe988a5f8708ecad3`（也可在 `project.config.json` 改为你自己的）；
3. 编译即可运行。**无需添加任何插件、无需云开发、无需网络**。

## 语音播报（离线、标准发音）
字母发音文件位于 `assets/audio/A.mp3 … Z.mp3`，由标准 TTS 生成（清晰、自然的英文字母名读音），打包进小程序，**运行时不联网**。要替换发音，只要把同名文件覆盖即可（支持 mp3 / wav 等 `innerAudioContext` 支持的格式，并同步修改 `utils/audio.js` 的后缀）。

> 说明：当前音频取自公开 TTS 接口，适合个人/内部试用。若计划**公开发布**，建议使用有授权来源的音频（如腾讯云 TTS / 微软 TTS 生成的文件），以避免第三方音频的授权风险。

## 视觉说明（掉落字母样式）
每个字母渲染为**彩色圆角徽标**：
- 背景色：从 8 色板随机取色（橙/红/蓝/绿/紫/黄/青/粉）+ 白色描边，像彩色图标方块；
- 白字加粗居中；
- 尺寸、落地判定、点击命中范围在 `pages/game/game.js` 的 `spawnLetter / update / draw / onTapCanvas` 中维护。

## 与安卓版（letterdrop）的关系
- **本版是独立重做的反向玩法**：安卓版是"念字母识别"，本版改为"App 报字母、玩家点"；
- **可复用**：字母集、外研版词库、UI 配色、Canvas 渲染思路；
- **不再需要**：Vosk / 腾讯云 ASR / 微信同声传译插件 / 云开发（全部移除）。
