# 字母掉落 · 微信小程序版（letterdrop-wx）

英文字母从屏幕顶部掉落，玩家**念出字母读音**（或**点击**字母）让它在落地前消失，落地算失败。基于原生微信小程序（WXML / WXSS / JS）开发，是安卓版 `letterdrop` 的小程序移植。

## 玩法
- 字母大小写随机掉落，顶部实时显示 **得分 / 生命 / 速度档**；
- 答对（念对读音 或 点中字母）**+1 分**；
- 字母落地 **扣 1 生命**，3 次后游戏结束并弹出结算卡片（含最高分）；
- **自动加速**：基础为第 5 档，每得 **20 分**升 1 档，无上限；
- 最高分本地存储（`wx.setStorageSync`），重玩自动刷新。

## 技术栈与结构
```
letterdrop-wx/
├── app.js / app.json / app.wxss   全局入口、页面注册、主题样式
├── project.config.json           工程配置（appid: wxe988a5f8708ecad3）
├── sitemap.json
├── config/
│   └── gameConfig.js             ★ 字母集 + 速度公式 + 语音映射 + 外研版词库
├── utils/
│   └── speech.js                 ★ 语音接口：腾讯云 ASR（云函数一句话识别）/ 点击降级
└── pages/
    ├── index/                    主页：背景 + 开始按钮 + 最高分
    └── game/                     游戏页：Canvas 掉落 + HUD + 结束卡片
```
- 渲染：`canvas type="2d"` + `requestAnimationFrame` 游戏循环；
- 存储：`wx.setStorageSync('letterdrop_best')`（替代安卓版 SharedPreferences）；
- 语音：**腾讯云 ASR「一句话识别」**（云函数 `cloudfunctions/asr` 代理），对应安卓版 Vosk；云环境不可用时自动降级为**点击消除**模式。录音采用 `RecorderManager` 循环短录音（wav/base64）调用云函数，识别结果经 `matchLetter` 模糊映射到字母。

## 运行 / 调试
1. 打开 **微信开发者工具** → 导入项目 → 选择本目录；
2. AppID 已配置为 `wxe988a5f8708ecad3`（也可在 `project.config.json` 改为你自己的）；
3. 编译即可运行。未接入语音插件时，自动进入**点击消除**模式（点下落的字母得分），用于验证玩法。

## 启用语音识别（腾讯云 ASR + 云开发）
"念字母消除"通过**腾讯云语音识别**实现，密钥放在云函数里（不进客户端）。整体流程：小程序录音 → 云函数 `asr` 调腾讯云 ASR → 返回文字 → 匹配字母消除。

### 一次性配置
1. **开通云开发**：微信开发者工具 → 顶部"云开发" → 开通，创建环境，复制**环境 ID**；
2. 把环境 ID 填进 `app.js` 的 `wx.cloud.init({ env: 'YOUR_CLOUD_ENV_ID' })`（替换占位符）；
3. **开通腾讯云 ASR**：登录 https://console.cloud.tencent.com/asr ，实名后开通「语音识别」，在 **访问管理 → API 密钥** 拿到 `SecretId` / `SecretKey`；
4. **部署云函数**：右键 `cloudfunctions/asr` → 上传并部署：**云端安装依赖**；
5. **配置环境变量**：云开发控制台 → 云函数 `asr` → 配置 → 环境变量，添加：
   - `TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`（必填）
   - `ASR_REGION`（可选，默认 `ap-guangzhou`）
   - `ASR_HOTWORD_ID`（可选，控制台创建的**热词表 ID**，把 A–Z 设为热词可显著提升字母识别率）
6. 重新编译，游戏中**念字母读音**即可消除；未配置云环境时自动降级为**点击消除**。

### 识别后处理（提升准确率的关键）
`utils/speech.js` 的 `matchLetter` 会把 ASR 返回的文字模糊映射到字母：直接命中 `SPEECH_MAP`（字母读音→字母）、包含匹配（如 "bee"、"letter b"）、以及纯单字母 A–Z。配合英语模型（`16k_en`）与可选热词，念字母识别足够稳定。

### 费用
两边都用免费额度：微信云开发有基础免费额度；腾讯云 ASR 新用户/每月赠送额度。轻度用量基本白嫖，重度按量计费（单次识别 cents 级）。详见计费页。

## 视觉说明（掉落字母样式）
每个字母渲染为**彩色圆角徽标**：
- 背景色：从 8 色板随机取色（橙/红/蓝/绿/紫/黄/青/粉）+ 白色描边，像彩色图标方块；
- 白字加粗居中；
- 尺寸、落地判定、点击命中范围在 `pages/game/game.js` 的 `spawnLetter / update / draw / onTapCanvas` 中维护。

如需改为"图片 + 字母"或 emoji 图标，调整 `draw()` 即可。

## 与安卓版（letterdrop）的关系
- **可复用**：玩法规则、计分/加速公式、外研版词库、UI 流程、配色；
- **平台替换**：Vosk 离线识别 → 腾讯云 ASR 在线识别（小程序禁止原生 `.so`，需联网）；
- **不适用**：固定调试签名（小程序无签名，上传即覆盖）。
