# 字母拼拼 · 微信小游戏版（letterdrop-wx）

一款面向幼儿英语启蒙的**原生微信小游戏**（Canvas 2D，无 DOM / 无 WXML）。包含两个模式：

- **找字母**：App 用标准语音**播报一个字母**，屏幕上 **6 个字母分两排从顶部掉落**（每排 3 个），玩家要在落地前**点中**与播报对应的字母（听音辨形）。
- **拼单词**：App **逐字母拼读一个单词**（进入时自动播一遍，也可点小喇叭重听），屏幕给出比单词长 2~3 倍（至少 6 个）的小写候选字母，玩家点选拼出单词；拼对后弹框显示单词与中文释义，可点「下一个」继续。

> 完全离线：语音播报用包内预录的标准发音文件，无需任何插件、云端或网络。

## 玩法规则（找字母）
- 每组掉落 **6 个字母（3 列 × 2 排）**；
- 开局 App **语音播报目标字母**，画面顶部**只显示「得分」**（不再显示目标字母，请听音辨别）；
- 每组中**正确答案最多出现 2 个**（大小写合计，即目标字母可能以大写/小写出现 1~2 次），其余为干扰项；
- **点中正确字母 +1 分**；**点错（点到干扰项）扣分**（不低于 0）；
- 目标字母**落地（漏点）则扣 1 生命**，3 次后游戏结束，显示结算页（含最高分）；
- **慢慢变快**：每完成 **10 组**速度 +1 档，无上限；
- 字母大小写随机显示，**不区分大小写**（B 与 b 都算对）；
- 最高分本地存储（`wx.setStorageSync`），重玩自动刷新。

## 玩法规则（拼单词）
- 词库为**外研剑桥《Join In 三年级上册》**（Welcome unit + Unit 1~5，详见 `data/words.js`），可按单元选择，也可用「全部章节」一次性练习；
- 进入某个单词后，App **逐字母拼读**该词（进入自动播一遍，点底部小喇叭可重听）；
- 屏幕给出 **2~3 倍于单词长度（至少 6 个）的小写候选字母**，全部小写；
- 点击候选字母**追加**到输入框并高亮（右上角对勾）；**再次点击已选字母可取消**（从输入框移除），重新点选则追加到末尾；
- 每次点击后**自动判定**：当输入框内容与该单词完全一致即视为拼对，弹出提示框显示**单词 + 中文释义**，点「下一个」进入下一个单词；
- 一个章节的单词全部完成，自动返回章节选择页。

## 技术栈与结构（微信小游戏）
```
letterdrop-wx/
├── game.js             ★ 入口 + 全部玩法/渲染/状态机（导航页/找字母/拼单词 均用 Canvas 绘制）
├── game.json           小游戏运行配置（竖屏、隐藏状态栏）
├── project.config.json 工程配置（compileType: game）
├── assets/audio/       ★ 26 个字母标准发音 mp3（A.mp3 … Z.mp3，打包进包，离线播放）
├── config/
│   └── gameConfig.js   ★ 找字母玩法参数（组大小/列数/提速/计分等）
├── data/
│   └── words.js        ★ 拼单词词库：外研剑桥 Join In 三年级上册（按单元 + 全部）
└── utils/
    └── audio.js        ★ 离线播放字母发音（包内 mp3，无插件/云）；含 announceWord 逐字母拼读
```
- 渲染：`wx.createCanvas()` 主画布 + 全局 `requestAnimationFrame` 循环；
- 输入：`wx.onTouchStart` 处理点击；
- 音频：`wx.createInnerAudioContext()` 播放 `/assets/audio/<字母>.mp3`，`obeyMuteSwitch=false`（静音模式也播报）；
- 存储：`wx.setStorageSync('letterdrop_best')`；
- **无任何云端/插件依赖**，导入即可编译运行。

## 语音播报（离线、标准发音）
字母发音文件位于 `assets/audio/A.mp3 … Z.mp3`，由标准 TTS 生成（清晰、自然的英文字母名读音），打包进小游戏，**运行时不联网**。要替换发音，只要把同名文件覆盖即可（支持 mp3 / wav 等 `innerAudioContext` 支持的格式，并同步修改 `utils/audio.js` 的后缀）。

> 说明：当前音频取自公开 TTS 接口，适合个人/内部试用。若计划**公开发布**，建议使用有授权来源的音频（如腾讯云 TTS / 微软 TTS 生成的文件），以避免第三方音频的授权风险。

## 视觉说明（掉落字母样式）
每个字母渲染为**彩色圆角徽标**：
- 背景色：从 8 色板随机取色（橙/红/蓝/绿/紫/黄/青/粉）+ 白色描边，像彩色图标方块；
- 白字加粗居中；
- 尺寸、落地判定、点击命中范围在 `game.js` 的 `spawnLetter / update / draw / onTapLetter` 中维护（现合并在 `game.js` 内）。

## 与安卓版（letterdrop）的关系
- **本版是独立重做的反向玩法**：安卓版是"念字母识别"，本版改为"App 报字母、玩家点"；
- **可复用**：字母集、外研版词库、UI 配色、Canvas 渲染思路；
- **不再需要**：Vosk / 腾讯云 ASR / 微信同声传译插件 / 云开发（全部移除）。
