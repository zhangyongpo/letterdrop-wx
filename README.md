# 字母拼拼 · 微信小游戏版（letterdrop-wx）

一款面向幼儿英语启蒙的**原生微信小游戏**（Canvas 2D，无 DOM / 无 WXML）。两个主模式：

- **找字母**：App 播报一个字母，6 个字母分两排从顶部掉落，落地前点中对应字母（听音辨形，带计分/闯关）。
- **拼单词**：六册教材词库 + 四种练习（听音拼单词 / 中文转单词 / 全部单词查阅 / 单词对对碰），含单词级真实发音。

> 完全离线：所有发音为包内 mp3，运行时不联网、无后端、无插件。

## 玩法规则

**找字母**：每组 6 个字母（3 列 × 2 排）；正确答案最多 2 个（大小写合计）；点中 +1 分、点错倒扣（不低于 0）、目标落地漏点扣 1 命；3 命结束结算；每 10 组速度 +1 档；最高分存 `wx.setStorageSync('letterdrop_best')`；游戏中退出有二次确认。

**拼单词**：路径为 `导航 → 年级/册次 → 章节（各单元 + 全部章节）→ 练习模式`。年级页为可上下滑动的卡片列表，按下记录命中、抬手且未判定为滑动才进入，避免滑动误触。
- **听音拼单词 / 中文转单词**：共用拼写页，前者自动播真实发音、底部小喇叭可重听；后者不发音、显示中文释义。候选字母为词长 2~3 倍（≥6，全小写），点击追加、再点取消，完全一致即拼对并弹框展示单词 + 释义。
- **全部单词查阅**：去重后按章节列出中英文，可上下拖动，每行小喇叭点播发音。
- **单词对对碰**：自适应流式网格，随机取最多 14 词，英文卡 + 中文卡配对消除，成功有翻转变绿动画。

含空格的短语（如 `on top of the world`）、连字符词（如 `forty-five`）和撇号词（如 `two o'clock`）有真实发音、可在查阅页播放，但不进入逐字母拼写练习。拼写页用 `assets/fonts/andika.ttf`（SIL 开源印刷体）绘制英语四线三格。

## 分包与包体

主包只保留启动必需内容，六册发音各放一个分包（`game.json` 的 `subpackages`）。点册次卡片时调用 `wx.loadSubpackage`，显示进度条；下载由微信本地缓存，之后进入无需再等；失败可重试或「仍要进入」（发音自动回退为逐字母拼读，不阻塞玩法）。分包内容仍受内容合规约束，老版本客户端由微信后台下发整包兼容版。

音频格式统一为 **MPEG-1 Layer3 / 44100Hz / 单声道 / 64kbps**——低采样率 MPEG-2 mp3 在 iOS 上会拒播，不要改采样率。

| 项 | 当前体积 | 官方上限 |
|---|---|---|
| 主包 | 0.95 MiB | 4 M |
| 六个分包合计 | 12.18 MiB（944 个 mp3） | 单个不限 |
| 总包 | 13.13 MiB | 30 M（部分情形按 20 M 计） |

## 生成 / 更新发音

```bash
python -m pip install edge-tts imageio-ffmpeg
python tools/gen_words_audio.py                 # 全部册次，跳过已存在文件（可断点续跑）
python tools/gen_words_audio.py --grades g3b    # 只补某一册
python tools/gen_words_audio.py --force         # 全部重新生成
python tools/gen_words_audio.py --manifest-only # 只按现有 mp3 重建 data/word_audio.js
```

脚本通过 `node tools/dump_audio_words.js` 读取 JS 词表（单一数据源），词条转文件名的规则见 `data/book_index.js` 的 `slug()`：小写、空格转下划线、撇号去掉（`two o'clock → two_oclock`）、连字符保留。生成完自动写入按册次分组的 `data/word_audio.js`。个别缩写有发音覆盖（`PE → P E`、`TV → T V`、`Mr → Mister`、`Ms/Mrs → Miss`、`OK → okay`）。

## 运行 / 调试

1. 微信开发者工具 → 导入项目 → 选择本目录；`compileType: game`，AppID `wx4de65122514bb5e0`。
2. 编译即可运行，无需插件 / 云开发 / 合法域名。
3. **务必真机（iOS + 安卓）验证一次**：选任一册次，等分包下载完成后听单词发音是否出声。若主包按绝对路径访问分包音频在某些客户端受限，会走逐字母拼读回退——此时需调整音频路径或改用分包异步化。
4. 正式发布需走「类目设置 → 资质审核 → 小程序备案 → 版本审核 → 发布」，不走虚拟支付的 IAA 路径预计 13~37 个工作日；分包不改变这条链路，也不额外收费。
